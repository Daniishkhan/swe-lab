BFS, DFS, topological sort and components

Graph algorithms mostly come down to one loop: take a node from a container, visit it, and put its unvisited neighbors back in. Whether that container is a queue or a stack decides almost everything about how the search behaves.

CoreThe one-sentence idea

BFS uses a queue and explores in rings of increasing distance, so it finds shortest paths in unweighted graphs. DFS uses a stack (or recursion) and goes deep first, which is what you want for cycles, orderings and exhaustive search. Both are O(V + E).

Build itFrom first principles

1. The generic search

seen = {start}
frontier = [start]
while frontier:
    node = frontier.take()          # queue → BFS, stack → DFS
    for nxt in neighbors(node):
        if nxt not in seen:
            seen.add(nxt)           # mark when you ADD, not when you take
            frontier.put(nxt)

Every node enters the frontier once and every edge is examined once (twice if undirected): O(V + E). The seen set is what stops you looping forever on cycles.

2. BFS: rings around the start

A FIFO queue finishes everything at distance d before touching distance d + 1. So the first time BFS reaches a node, it got there by a shortest path (in edge count). Use it for: shortest path in a grid or maze, minimum moves, word ladder, level-order traversal, and multi-source BFS (rotting oranges, distance to the nearest exit).

3. DFS: go deep, backtrack

A stack (or the call stack) follows one path to its end before trying alternatives. DFS gives you a notion of entering and leaving a node, and that's what makes these possible:

  • Cycle detection (directed): three colors: white (unvisited), gray (on the current path), black (finished). Meeting a gray node means you found a back edge, which means a cycle.
  • Topological sort: list nodes in reverse finishing order. A node finishes only after everything it points to has finished.
  • Connected components: run DFS from every unvisited node; each run is one component. (Union-find does the same incrementally.)

4. Topological sort, the BFS way (Kahn's algorithm)

Repeatedly take a node with no remaining prerequisites (in-degree 0), output it, and remove its outgoing edges. If you output fewer than V nodes, the leftover nodes form a cycle. It's often easier to explain than the DFS version, and it detects cycles for free.

IntuitionAnalogies

BFS: a ripple in a pond

The wave reaches everything at distance 1, then 2, then 3. Whatever the ripple touches first, it reached by the shortest route.

DFS: exploring a maze with one hand on the wall

Walk until you hit a dead end, then back up to the last junction with an unexplored corridor. Thorough, but the first time you reach the exit isn't necessarily the shortest way.

Topological sort: getting dressed

Socks before shoes, shirt before jacket. Any order that respects every "before" rule works. A cycle (shoes before socks before shoes) means there is no valid order.

InterviewWhat a senior answer adds
  • Choose deliberately: "shortest" plus unweighted means BFS. Need all paths, an ordering, or cycle structure? DFS. Weighted edges mean Dijkstra (a BFS whose queue is a heap).
  • Recursion limits: recursive DFS on a 10⁶-cell grid crashes Python. Offer the iterative version, or sys.setrecursionlimit with a caveat about stack memory.
  • Real-world graphs: build systems and package managers (topological sort plus cycle errors), deadlock detection (cycles in a wait-for graph), web crawlers (BFS with politeness limits), garbage collectors (mark phase = graph traversal from roots).
  • Bidirectional BFS from both ends meets in the middle and explores roughly 2·b^(d/2) nodes instead of b^d. That's a good follow-up for word ladder.
TrapsCommon mistakes
  • Marking visited when you pop instead of when you push in BFS: nodes get queued many times, and on dense grids that blows up.
  • Using list.pop(0) as a queue (O(n)). Use deque.popleft().
  • Directed cycle detection with a single visited set. You need the gray/black distinction: reaching a black node isn't a cycle.
  • Forgetting disconnected parts: loop over all nodes as possible starting points.
RecallCheck yourself
Why does BFS give shortest paths but DFS doesn't?

The FIFO queue processes nodes in non-decreasing distance order, so the first discovery of a node uses a minimum-edge path. DFS's order depends on which branch it happened to try first.

Grid with 0/1 edge weights: BFS or Dijkstra?

0-1 BFS: a deque where 0-cost edges go on the front and 1-cost edges on the back. O(V + E), no heap needed.

How do you detect a cycle in an undirected graph?

DFS that ignores the edge back to the immediate parent; any other visited neighbor means a cycle. Or union-find: an edge whose endpoints are already connected closes a cycle.
