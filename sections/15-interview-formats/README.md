# §15 Interview Formats to Rehearse

Open `index.html` in this folder for the interactive chapter view (status tracking, links to concept pages and exercises).

## Topics

- [ ] `15.01` **[Format]** Algorithmic coding (45 to 60 min, one or two problems)
- [ ] `15.02` **[Format]** Practical coding: build a small working component with tests, often multi-part with growing requirements
- [ ] `15.03` **[Format]** Debugging round: broken code or failing tests in an unfamiliar repo
- [ ] `15.04` **[Format]** Code review round: critique a pull request
- [ ] `15.05` **[Format]** System design (high-level architecture)
- [ ] `15.06` **[Format]** Low-level / object-oriented design
- [ ] `15.07` **[Format]** Concurrency-focused coding
- [ ] `15.08` **[Format]** Take-home or pair-programming project
- [ ] `15.09` **[Format]** AI-assisted coding round (where permitted): graded on direction, verification, and judgment
- [ ] `15.10` **[Format]** Project retrospective / past work deep dive
- [ ] `15.11` **[Format]** Behavioral and values round
- [ ] `15.12` **[Format]** Hiring manager round
