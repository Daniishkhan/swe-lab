# TypeScript track (later)

Python is the primary language for this repo. When it's useful to practice in
TypeScript too (frontend-leaning roles, or to compare idioms), mirror an exercise
here as `ts/<chapter>/<name>.ts` with a `<name>.test.ts` next to it, and run them
with `npx vitest`. Nothing is set up yet on purpose; add a `package.json` the day
the first TypeScript exercise lands.
